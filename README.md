
# 🌐 Pokédex Web - Projeto ADS

Uma Pokédex interativa desenvolvida como projeto prático para a disciplina de Análise e Desenvolvimento de Sistemas. O sistema consome dados da **PokeAPI** para listar, buscar e detalhar informações sobre os Pokémon em tempo real.

## 🚀 Funcionalidades

- **Listagem Dinâmica:** Carregamento automático dos Pokémon via API.
- **Paginação:** Botões de "Próxima Página" e "Página Anterior" para navegar pelo catálogo.
- **Busca Inteligente:** Pesquisa por nome ou ID, com suporte à tecla "Enter".
- **Sistema de Favoritos:** Permite salvar seus Pokémon preferidos no navegador usando `localStorage`.
- **Detalhes Expandidos:** Visualize imagem, tipos, ID, altura e peso ao clicar em um card.
- **Design Responsivo:** Layout adaptável para dispositivos móveis e desktops utilizando CSS Grid e Flexbox.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS:** Estilização moderna, efeitos de blur (Glassmorphism) e design responsivo.
- **JavaScript (Vanilla):** Lógica de consumo de API (Fetch API), manipulação do DOM e armazenamento local.
- **PokeAPI:** Fonte de dados oficial dos Pokémon.
